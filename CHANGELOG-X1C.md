# Changelog — ThinkPad X1 Carbon Gen 11 port (branch `x1c-g11`)

Fork of [JulioNectar/Hackintosh-XPS13Plus-IrisXe-Tahoe](https://github.com/JulioNectar/Hackintosh-XPS13Plus-IrisXe-Tahoe)
for the **Lenovo ThinkPad X1 Carbon Gen 11** (i7-1355U, Raptor Lake-U, Iris Xe `8086:A7A1`, 96 EU,
1920×1200 IPS eDP), targeting macOS Tahoe 26.7.1 (25G241).

**Nothing in this fork is tested.** Every entry is a change made from hardware data or source reading;
status moves to "confirmed" only after a boot on the real machine.
